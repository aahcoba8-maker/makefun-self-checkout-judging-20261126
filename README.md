One funny line in the voice of a smug self-checkout machine, judging a 2am basket of one instant noodle and four energy drinks.

## Entry

> 02:00 AM. One instant noodle, four energy drinks. Remaining sleep calculated: zero. Please scan your will to live next.

119 characters, one line, no padding.

## Run

```sh
python3 main.py
```

Prints the line to stdout and writes it to `entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
